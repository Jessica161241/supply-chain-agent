## 段落 4 · 协同策略（2:30-3:30）

**画面**：05_final_demo 的 alpha 扫描表

**旁白**：
"核心创新点是聚合缺口信号协同机制。下级节点把需求缺口聚合成一个
隐私保护的信号上报给上级，上级据此调整补货量。信号只暴露聚合量，
不含单笔订单。通过 alpha 参数扫描发现协同强度存在相变临界：
alpha 从 0 增大到 1.0 时成本持续下降（1.0 处最低 16040）；
但 alpha=1.05 时系统进入正反馈式过量订货，成本骤升到 35557，
是 1.0 处的 2.2 倍。这就是相变临界。"

## 段落 5 · A/B 对比（3:30-4:30）

**画面**：fig_benchmark_summary.png + fig_bullwhip_amplification.png

**旁白**：
"365 天完整仿真对比：协同策略让总成本从 22564 降到 16576，降幅 26.5%；
可优化层 fill rate 从 92.8% 微升到 94.9%——服务率不降反升。核心价值
在于中间层欠货深度从 -21.9 缓解到 -5.8，缓解约 73%。牛鞭系数和总成本
的解耦说明协同不是用成本换服务，而是双赢。我们最终选用 alpha=0.8，
距相变（alpha>1.0 处成本骤升 2.2 倍）保留约 20% 安全边际。"
